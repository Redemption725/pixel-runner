# 霓虹疾行 · Neon Rush 3D

一款 Three.js 真 3D 三车道跑酷网页游戏：立体列车、发光金币、霓虹都市、辉光与雾效，电脑 / 手机双端适配。

## 玩法
- 三车道自动疾行，速度越来越快；
- **立体列车无法跳跃，必须提前换道**；跳过矮障、下滑穿过高杆；
- 收集发光金币，撞击即结束，可一键重开。

## 操作
| 动作 | 电脑 | 手机 |
| --- | --- | --- |
| 左 / 右换道 | ← → 或 A / D | 左右滑动 |
| 跳跃 | ↑ / W / 空格 | 上滑 / 点屏 |
| 下滑 | ↓ / S | 下滑 |
| 暂停 | P 或右上角按钮 | 右上角暂停按钮 |

## 特性
- Three.js WebGL 真 3D，透视跟随镜头；
- 软阴影、ACES 色调映射、sRGB、UnrealBloom 辉光、雾效；
- PBR 材质（金属钢轨、发光金币与车窗）；
- 最远纪录本地持久保存；切后台自动暂停；dt 上限防穿墙。

## 运行
首次需联网加载 Three.js（之后浏览器缓存），双击 `index.html` 即可，也可部署到任意静态托管。

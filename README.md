# 像素地铁跑酷 · Pixel Subway Runner

一款像素风三车道跑酷网页游戏，单文件 HTML + Canvas，无需安装、双击即玩，电脑 / 手机双端适配。

## 玩法
- 角色在三条车道间自动向前奔跑，速度随距离越来越快；
- 躲避 **列车**（无法跳跃，必须提前换道）、跳过 **矮障**、下滑穿过 **高杆**；
- 收集金币加分，撞到障碍游戏结束，可一键重开。

## 操作
| 动作 | 电脑 | 手机 |
| --- | --- | --- |
| 左 / 右换道 | ← → 或 A / D | 左右滑动 |
| 跳跃 | ↑ / W / 空格 | 上滑 / 点屏 |
| 下滑 | ↓ / S | 下滑 |
| 暂停 | P 或右上角按钮 | 右上角暂停按钮 |

## 特性
- 伪 3D 透视道路、滚动枕木与车道线；
- 像素小人（跑步 / 跳跃 / 下滑姿势）、像素天空与远景城市；
- 距离与金币统计、碰撞像素碎片特效；
- 最远纪录本地持久保存（localStorage）；
- 切后台自动暂停、dt 上限防穿墙。

## 本地运行
直接双击 `index.html` 用浏览器打开即可，无需任何依赖或构建。

## 技术栈
原生 HTML / CSS / JavaScript + Canvas，无第三方库、无构建工具。
